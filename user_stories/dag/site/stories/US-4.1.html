User Story

As a
user who has configured accounts, defined categories, labelled receipts, and matched them to CSV transactions
I want to
run `./start.sh` and have the entire pipeline execute: validate config, preprocess CSVs, run hledger-flow import, consolidate journals, and generate plots
So that
I get a complete `all-years.journal` and financial visualisations with a single command.

Acceptance Criteria

  • `start.sh` exits 0 on success.
  • `all-years.journal` includes all bank transactions and receipt-based transactions.
  • The starting position journal (`start_journal_filepath`) is included.
  • Plot SVGs are generated in the output directory.
