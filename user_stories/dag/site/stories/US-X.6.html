US-X.6implemented Enforce one receipt image per transaction
As a user who wants a clean 1:1 relationship between receipt photos and receipt labels I want the system to enforce that each receipt label references exactly one receipt image, and each image is used by at most one label so that there is no ambiguity about which photo belongs to which transaction.
